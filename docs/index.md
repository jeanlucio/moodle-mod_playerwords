**PlayerWords** is a word-guessing vocabulary activity for Moodle. Students guess a hidden word
letter-by-letter within a configurable number of attempts, receiving colour-coded and symbol
feedback on each guess.

O **PlayerWords** é uma atividade de adivinhação de palavras para o Moodle. O estudante adivinha
uma palavra oculta letra por letra dentro de um número configurável de tentativas, recebendo
feedback visual em cores e símbolos a cada chute.
